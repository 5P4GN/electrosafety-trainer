# Тренажёр по электробезопасности

Мобильный PWA-тренажёр для подготовки на II группу по электробезопасности до 1000 В.

**[Открыть тренажёр](https://5p4gn.github.io/electrosafety-trainer/)**

- 97 проверенных вопросов: 87 исходных и актуальные дополнения;
- режимы на 10, 20, все или только новые вопросы;
- перемешивание вопросов и вариантов ответа;
- повторение ошибок и локальная статистика;
- установка на экран «Домой» и работа офлайн после первого открытия.

## iPhone

Откройте опубликованную ссылку в Safari, нажмите «Поделиться» и выберите «На экран Домой».

Все данные и статистика остаются в браузере устройства. Серверная часть не используется.
